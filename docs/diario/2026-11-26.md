  - `test/usuarios.test.js`: 2 pruebas: el hash no contiene la contraseña y solo la correcta coincide; roles válidos, correo repetido rechazado y rol inventado rechazado (por el código y por la base).

## Paso 2 · Login y sesiones
- **Parte del correo que cumple:** «al menos 2 usuarios con login propio ven las mismas conversaciones» (base del criterio 4: dos usuarios en dos navegadores).
- **Qué se hizo:**
  - `src/db/esquema.sql`: tabla `sesiones`. Guarda el **hash SHA-256** del token de sesión, no el token: si alguien copiara la base, no podría usar esas sesiones.
  - `src/nucleo/sesiones.js`: iniciar sesión (correo y contraseña), saber quién es el dueño de una sesión y cerrarla. Cada sesión dura 8 horas (un turno); las vencidas se borran solas. Si el correo no existe, la contraseña se compara igual contra un hash de relleno, para que la respuesta tarde lo mismo y no revele qué correos existen.
  - `src/rutas/sesion.js`: `POST /api/login`, `POST /api/logout` y `GET /api/yo` (usuario actual). La sesión viaja en una cookie **HttpOnly** (el JavaScript de la página no la puede leer) y **SameSite=Strict** (otros sitios no la pueden usar). Para correo o contraseña incorrectos el mensaje es el mismo: «Correo o contraseña incorrectos». También deja listo el filtro `requerirSesion`, que se usará en la API de la bandeja: sin sesión responde 401.
  - `src/app.js`: se conectaron las rutas en `/api`. Sin librerías nuevas.
  - `test/sesion.test.js`: 4 pruebas: login incorrecto (401, sin cookie y sin sesión guardada); login correcto (cookie HttpOnly y Strict, API con 401 sin sesión o con un token inventado, token no guardado en texto); dos usuarios con sesiones independientes y cierre de sesión; sesión vencida.
- **Resultado:** `npm test` → **17 pruebas, 17 pasan**. Prueba con el servidor real y los usuarios de `data/bandeja.db`: sin sesión → 401; contraseña mala → 401; Laura, Pedro y la Coordinadora entran (200); tras cerrar sesión, la cookie de Laura ya no sirve (401).
- **Archivos:** `src/db/esquema.sql`, `src/nucleo/sesiones.js`, `src/rutas/sesion.js`, `src/app.js`, `test/sesion.test.js`, `test/base-datos.test.js`.
- **Pendiente para el paso 3:** API de la bandeja (conversaciones y mensajes), protegida con sesión.
